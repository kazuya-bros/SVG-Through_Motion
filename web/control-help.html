AI操作・OBS・素材出力

スタジオで素材を開き「AI・OBS接続を開始」を押してください。この操作で音声の再生を有効にします。操作対象は接続した編集画面1つです。編集画面を閉じると接続も終了します。SpriTalkやクラウドAIの契約は必要ありません。

AI・スクリプトからの操作

ローカルREST APIを使います。対話式API仕様とOpenAPI JSONから引数を確認できます。MCPサーバーは同梱していません。シェル・HTTPリクエストを使えるAIから呼び出せます。

GET  /api/control/status
GET  /api/projects
POST /api/control/commands
GET  /api/control/commands/{id}

POSTの202は受付を表します。返されたresult_urlをGETし、statusがcompletedまたはfailedになるまで確認してください。resultに保存先や実行結果、errorに失敗理由が入ります。同時実行は1件。stopは処理中でも送れます。再送すると別の操作になるので、応答不明時は状態を確認してください。

poseは解除するまで優先します。発話前はposeをresetすると音声で口が動きます。speakは画面で選んだエンジン・声を使い、発話終了までrunningです。SBV2・VOICEVOX・AivisSpeech・Irodori-TTS（Aratako版OpenAI互換）・ブラウザ標準に対応します。ローカルTTSサーバーは別途起動してください。ブラウザ標準は簡易口パクで、WAV保存・動画への音声収録はできません。readingは省略できます。口パクは開閉モードです。readingは互換性のため受け付けますが、母音切替には使用しません。stopは音声・マイク・今回追加した素材出力を停止し、口形固定を解除します。既存のWebM/MP4録画の中断は対象外です。

同梱のPythonクライアント

python tools/studio_control.py status
python tools/studio_control.py projects
python tools/studio_control.py command '{"action":"play"}'
python tools/studio_control.py command @command.json
python tools/studio_control.py --url http://127.0.0.1:8766 status

標準ライブラリのみ。既定では完了を待ちます。--no-waitで受付後に戻り、result IDで確認できます。接続が切れたときは操作を自動再送しません。履歴は直近100件で、サーバー再起動で消えます。

OBSで表示

  1. スタジオでAI・OBS接続を開始。
  2. OBSでブラウザソースを追加し、スタジオに表示された /web/obs.html のURLを指定。
  3. 幅・高さを配信レイアウトに合わせて設定。背景は透過、比率を維持して中央に表示。
  4. 編集後は「編集内容をOBSへ反映」。口パクやカメラの動きは接続中に送信。

OBSページには映像のみを出します。TTS・音声ファイルはスタジオのブラウザ音声をOBSで取得し、マイクはOBSのマイク入力を使ってください。二重取り込みを避け、音声と映像の遅延はOBS側で確認してください。マイクはスタジオで明示的に開始し、権限を許可します。OBS自身にマイク権限は不要です。

編集画面のタブを休止させるとリアルタイム口パクが止まります。別ウィンドウで開いて維持してください。接続断ではOBSを透明に戻し、再接続後に表示を復元します。確認用は /web/obs.html?debug=1。OBS本番にはdebugを付けないでください。

素材を持ち出す

透過PNG連番・スプライトシートZIPにはanimation.jsonを同梱します。固定fps、最大600コマ、音声なし。指定秒数をfpsで表せる最寄りのコマ数へ丸め、実際の秒数をJSONに保存します。原画のキャンバス全体を縮小し、拡大・トリミングはしません。シートは最大4096pxで複数ページに分かれます。

素材出力はループの設定を使います。マイク・カメラ・AIで固定した確認用の口形は入りません。現在のポーズは静止PNGで保存できます。PNG連番は動画編集へ、シートはゲームへ取り込んでください。既存のMP4は白背景です。

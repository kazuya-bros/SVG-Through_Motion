# SVG-Through Motion

## v0.1.0-preview

元絵とSee-Throughで分割したPSDから、立ち絵をSVG化して動かすWindows向けのテスト公開版です。

### できること

- 目・口の補正、瞬き、口パク、顔向き
- 髪・耳・翼・服・小物の揺れ
- SVGの色変更、ライティング、線・色の出現などの演出
- 配信向け表示、ホットキー、透過WebM／MP4保存
- プレビューの中央ドラッグ移動とホイールズーム

### 使い方

1. GitHub ReleasesからWindows用ZIPをダウンロードして展開します。
2. 起動後、元絵とSee-Throughで分割したPSDを読み込みます。
3. 「01 形を整える」で目・口を確認し、「02 動きをつける」で動きを調整します。
4. 「03 保存」で動画またはプロジェクトを保存します。

入力画像とPSDは同じキャンバスサイズ・位置で用意してください。パス数の多い素材や複数の揺れを同時に使うと、プレビューやWebMの再生が重くなる場合があります。

この公開版は動作確認と展示を目的としたプレビューです。素材や環境によって変換結果や動作速度に差が出ます。問題報告時はOS、入力画像のサイズ、PSDのレイヤー構成、再現手順を添えてください。

現在画面から隠している機能、AIによる外部操作、実験的な出力機能などのコードは含まれていますが、v0.1.0-previewでは利用できません。

### 開発者向け

ローカル起動は `Start-Studio.cmd` を使用してください。Python 3.10以上と `requirements.txt` の依存関係が必要です。

```powershell
.\Start-Studio.ps1
```

テスト：

```powershell
npm test
python -m unittest discover -s tests -p 'test_*.py'
```

詳細な仕様・検証記録は [`docs/`](docs/) を参照してください。

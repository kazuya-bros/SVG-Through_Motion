# 演出要素の選択編集とプレビュー描画

2026-09-20

## 変更

- 右ペインを演出名、表示時間、追加済み要素の一覧、追加操作、選択した要素の設定の順に整理。
- 表情・方向・時間・縁取り・照れなどの詳細は選択中の要素だけ表示。非表示の要素の値は保持し、既存の演出保存・プレビュー API を使用。
- 配信と演出編集のキャラクター描画では、SVG を一度描画したテクスチャの不透明画素の範囲を保持。透明な余白を省いてレイヤーと変形結果を合成する。
- 変形後の範囲は行列で保守的に拡張。範囲が不明な RIFE などの直接描画は全域へフォールバック。解像度、SVG データ、モーション設定は変更しない。

## 検証

- `tests/effects-list.browser.cjs`: 実素材24パーツで、選択した要素だけの表示、他要素の設定保持、保存内容、一覧の展開・追加・削除、無期限／時間指定プレビュー、消える・停止を確認。
- `tests/effects-performance.browser.cjs`: 1080px の元描画＋15%余白の条件で、新旧を同じ Chromium で比較。6つの姿勢・開閉状態で不透明部分の欠落なし。RGBA の平均絶対差は最大0.0088/255（サンプリングの丸め差）。
- 同テストの描画＋見た目処理の平均時間: 通常184.5→91.8ms、縁取り240.1→135.2ms。実測データは `output/verification/effects-cropping-performance.json`。GPU、表示倍率、ブラウザー、素材で変動し、ユーザー環境の FPS を示す数字ではない。
- Node テスト、演出／ランタイム／エージェント API の Python テスト成功。
- 実画面: `output/verification/effects-list-layout.png`。

## 残る制約

高密度の素材の変形や縁取りには描画コストが残る。この変更は透明領域の無駄な転送を減らすもので、すべての素材で滑らかな再生を保証するものではない。

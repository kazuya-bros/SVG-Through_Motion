## 実装順

1. 補正済み素材の永続化とPSD/SVGへの受け渡し。
2. 補正画面と追加パーツの関係・深度・動作確認。
3. See-Through実行・候補管理・補正後Depth生成。
4. 配信表情・入力、素材描画UIの整理。

RIFE補間の移植は別課題。今回の形状変形をRIFEと同品質とは扱わない。
See-Throughのコード・モデルはPachiPakuGenで確認済みの出所・ライセンス情報を引き継ぐ。
生成モデルの再取得や既存ランタイムの書換えを通常のPSD補正に要求しない。

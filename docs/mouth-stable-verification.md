# 口の中間変形補正の確認（2026-09-17）

この文書は元SVGの変形へ寄せた旧方式の検証記録。ユーザーの要望により、標準方式はRIFEの中間コマを使う方式へ修正した。現在の検証は [mouth-rife-contour-verification.md](mouth-rife-contour-verification.md) を参照。

## 原因と変更

既存の生成済み8枚を持つ20パーツの検証プロジェクトで、開口11%の薄い大きな輪郭を再現。閉じ口の次の生成コマ自体にも残像があり、隣接コマの上下範囲に合わせる処理が閉じ口を引き伸ばしていた。

口の標準方式を「輪郭を保って補間」に変更。元SVGの線と塗りを使い、RIFEグリッドからの形状補正を制限する。生成済み8枚は保持し、明示的に比較用再生を選べる。生成画像そのものを修復する変更ではない。瞬きは変更しない。

## 検証結果

- JavaScript 249件、Python control / agent control / MCP 17件成功。
- 更新後の凍結バックエンドを独立した18788ポートで起動し、実UIで既存データの読み込み、11%開口、再生方式切替、保存後の再読み込みを確認。
- APIで実効再生方式を取得し、stable / svg-frames-rawを切替できることを確認。
- SVG作業画面は補正したグリッドを使用し、rawモードは8枚のチャンネルを使用することを確認。
- Canvasで0%と100%が通常描画と画素一致。11%で非透明画素の平均alphaは従来62.67、補正後176.05（輪郭・開口形状も変わるため、単独の品質指標ではない）。
- 101段階の開閉走査で8%以降に描画停止なし。最後の変化量35720は、それ以前の最大128514を超えない。
- 実UIスクリーンショットと0〜100%の比較画像を目視確認。ブラウザの未処理例外なし。

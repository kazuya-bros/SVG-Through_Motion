# 02 動きをつけるの調整（2026-09-19）

- 新規変換・自然な動きへのリセットはループ口パクON。保存された明示的なOFFは維持。
- 髪飾りは飾りごとの追従先プルダウンに整理。連結・解除は既存APIの共通処理を使用。
- 胸の範囲編集時、プレビュー内に「この範囲で確定」「キャンセル」を固定表示。Escapeでもキャンセル。
- 耳は役割・保存された指定を使用。対象変更は「耳が別のレイヤーに含まれる場合」の詳細に収納。
- 顔の向きに前髪・後ろ髪・耳・眼鏡・頭飾りを連動。首を支点とし、奥行き差と独立した髪揺れを加える。ボディ・腕・服の裾の連動は増やさない。
- 左右の眉は高さと傾きを独立調整。即時プレビュー・既存表情の更新・別表情の追加に対応。傾きはAPIのstage poseにも追加。

## 範囲

頭部の連動は既存のメッシュ・画像キャッシュを使用する。新規のRIFE生成や毎フレームのSVG再変換は行わない。
元絵に隠れた側面を描き足す処理ではなく、小さい顔の向きの変化を対象とする。大きい角度や素材の切り抜き境界の品質は、キャラクターごとの確認が必要。

# 配信準備と同一ウィンドウの配信モード

## 変更

- メイン画面・管理設定のヘッダーを固定。
- 保存キャラクターの利用は同じページで読み込み、編集画面を経由せず live（配信準備）へ直接入る。直接URLの起動時も関係ない開始画面を隠して読み込み表示を出す。
- liveでも既存のドラッグ・ホイール操作を有効化し、位置・大きさのリセットを追加。
- 同じウィンドウで配信モードへ遷移。自動・マイク・カメラ・AIの選択を配信画面へ移す。
- 入力切替は受付変更成功後に旧入力を停止。失敗時は元の選択・入力を維持。重複切替を防止。
- 準備した構図を配信画面と配信ソフト用URLへ引き継ぐ。配信終了後は同じキャラクターと構図で準備へ戻る。
- 「アプリ設定」を「保存先と接続」として用途を説明し、Sの仮アイコンを本体と同じ3本線のロゴへ変更。
- 音声未設定でもマイク・カメラ・待機は利用でき、AI音声は準備画面で設定するよう案内。勝手に別の音声へ切り替えて話すことはしない。

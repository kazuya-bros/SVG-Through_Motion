# 演出作成の専用画面（2026-09-20）

- メインメニューに「演出を作る」を追加。保存履歴／プロジェクトファイルからキャラクターを選択してeffects-editor.htmlを開く。
- 専用画面はプレビュー、演出の作成・編集・保存に限定。配信準備には作成UIを設置しない。
- 描画とavatar APIは配信と共通。演出はproject_id付きで保存し、既存のホットキー割り当てに使用できる。
- 未保存の変更があるときは、ロゴ移動・新規作成・別演出の読込で破棄確認。保存後はそのままメインメニューに戻れる。
- Playwrightでメインメニュー→キャラクター選択→実際の24パーツプロジェクト読込→専用画面→3要素プレビュー→保存→ロゴで復帰を通過。配信準備から演出UIが消え、ホットキーが残ることも確認。JavaScriptエラーなし。

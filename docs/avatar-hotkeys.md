# アバターの組み合わせ演出

## 配信準備

メニューは「配信モードへ」「ホットキー設定」「背景」「制御方法（カメラ・音声）」の順。演出作成はメインメニューの「演出を作る」から行う。配信ソフト用URLのコピーは末尾に置く。パーツの色変更、保存先・接続、TTS、字幕、AI接続はこの画面に表示しない。既存APIは保持する。

## 演出を作る

1. メインメニューの「演出を作る」から、保存したキャラクターまたはプロジェクトファイルを選ぶ。左カラムのAddで演出を追加し、右カラムで名前や要素を編集する。演出名の矢印で組み合わせ要素を折り畳み／展開できる。保存済みの演出はDeleteで削除できる（標準の0/1を除く）。
2. 表情・通信・はずみ・縁取り・照れなどを最大10要素まで組み合わせる。同じ要素は1つ、登場・消滅はどれか1つ。
3. 動く要素は方向・時間・強さを指定。照れ・冷や汗・感情画像は角度も調整できる。照れ・冷や汗はプレビュー上で位置を指定できる。
4. 中央の「プレビュー」は未保存の内容を再生する。「次の演出を選ぶまで」では自動で戻らず、停止または別の演出への切替まで維持する。「指定時間だけ」の場合は終了時に戻る。再生中に左の別の演出を選ぶと、その演出に切り替わる。
5. 演出を保存する。ロゴからメインメニューへ戻り、「キャラクターを使う」の配信準備で「ホットキー設定」を開き、キーと登録演出を対応づけて保存・適用する。演出を後から編集してもIDは変わらず、キー割り当てを維持する。

表示時間は「次の演出を選ぶまで」または「指定時間だけ」。前者では表情・見た目・通信・光を維持し、はずみ・登場は指定時間で一巡する。全体の再生時間は設定時間と各動く要素の時間の最大値。指定時間だけの場合は終了後に通常の見た目へ戻る。

「キャラクターを表示」のチェックは廃止。「消える」要素は即座に非表示にする専用の演出で、他の要素とは組み合わせない。「サラサラ消える」は動きが終わった後に非表示を維持する。

標準演出は「0：消える」「1：通常表示」。新規のデスクトップ設定ではCtrl+Alt+0/1を割り当てる。既存のユーザー設定は上書きしない。ホットキーを有効にし、操作対象を選んで保存・適用する。ブラウザ単体ではグローバルキーを登録できない。

右側は「演出名 → 表示時間 → 追加済みの要素 → 要素の追加 → 選択中の要素の設定」の順です。要素名を押して切り替えます。ほかの要素の設定は保持されます。要素の追加・削除は自動でプレビューへ反映し、停止中でもプレビューを開始します。最後の要素を削除すると通常表示になります。自動反映では演出の保存は行いません。

## API / MCP

- GET `/api/avatar/presets?project_id=...`：標準演出と保存した演出。
- POST `/api/avatar/presets`：`{request_id:32桁hex, action:{name,project_id,kind:"bundle",components,appearance,visibility,behavior,duration}}`。同一ID・同一内容は重複作成しない。最大256件。
- PUT `/api/avatar/presets/{id}`：同じ保存引数と`revision`。競合は409。同じrequest_idの再送は同じ更新結果を返す。
- DELETE `/api/avatar/presets/{id}`：`{request_id:32桁hex,revision}`。競合は409。同じ削除要求の再送は同じ結果を返す。削除後は一覧と呼び出しの対象外になり、元IDを再利用しない。
- POST `/api/avatar/sessions/{sid}/preview`：`{request_id,action}`。未保存の組み合わせをプレビュー。
- POST `/api/avatar/sessions/{sid}/preview/stop`：`{request_id,expected_request_id}`。指定したプレビューだけ停止する。
- POST `/api/avatar/sessions/{sid}/trigger`：`{request_id,preset_id}`。
- GET `/api/avatar/sessions/{sid}/trigger/{request_id}`：描画側から届く実行結果。
- GET `/api/stage/sessions/{sid}/preview`：実際の合成画像を取得。
- MCP：`avatar.presets/save/update/delete/preview/stop_preview/trigger/result`。引数の詳細は`/api/agent/operations/{name}`。

UI、グローバルホットキー、APIは共通処理を利用する。演出はデータフォルダのavatar-actionsへ保存。別キャラクターの演出の誤適用、画像の存在、表情インデックス、範囲を検証する。選択を維持する演出のcompletedは初回の演出時間の完了を表し、表示解除を意味しない。OBSは同じ組み合わせと時間を受け取る。

色変更のAPIと旧単独演出は互換用に保持する。元絵・プロジェクトのSVGは上書きしない。

値の自動反映・速さ・追加エフェクト・キャラクター切替は [リアルタイム演出とキャラクター切り替え](effects-live-and-characters.md) を参照してください。

# 拡大比較と補修後のチェック

## 比較

「比較」でアニメーションと元画像を固定した左右の枠に表示する。どちらの枠でもホイールで拡大縮小、ドラッグで移動でき、両方の表示位置と倍率が同期する。中央の区切りと見出しは動かない。「全体」で倍率と位置を戻す。
素材・キャラクターの保存位置を変更する操作ではなく、作業用表示の調整。比較の拡大・ドラッグは画面用の機能。

## 補修後のチェック（任意）

「動きをつける」→「表情」の折りたたみ。通常は使わなくてよい。補修したパーツが、顔の向き・閉じ目・開いた口で隙間や重なりを生まないかを確認する一時表示。

- 「一巡を再生」: 正面・左右・上下・閉じ目・開いた口を順番に表示。
- 「ここで止める」: 現在の確認ポーズで止める。
- 「左を向く」など: 指定した確認ポーズを直接表示。
- 「確認を終える」、または折りたたみを閉じる: 通常のプレビューへ戻る。

確認ポーズはプロジェクトの動きや書き出す演出として保存されない。これはポーズを作って保存する機能ではない。

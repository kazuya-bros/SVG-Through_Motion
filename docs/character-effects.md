# キャラクターの演出

出力画面の設定欄にある「演出」から選びます。配信ソフト向けの表示URLにも反映します。

| 操作 | 動作 |
| --- | --- |
| サラサラ消える | キャラの色を持った粒が流れ、左から消えます。終了後は非表示を保ちます。 |
| 粒から現れる | 消える動きの逆再生で、通常表示に戻ります。 |
| 通信中 | 緑の色調、走査線、接続直後の小さな乱れ。時間が来ると戻ります。 |
| 幸せの光 | 顔の周囲に暖色の光と浮かぶ星。時間が来ると戻ります。 |
| 演出を止めて元に戻す | 演出を解除し、消えたキャラも通常表示に戻します。 |

強さは0〜100%、時間は画面では2〜30秒から選択します。APIは0.5〜30秒に対応します。演出は同時に1つで、新しい演出が前の演出を置き換えます。表情・口パク・顔の動きには重ねて使えます。

「発話が終わったら戻す」は、この出力で発話中に使えます。発話終了・停止・割り込み、または指定時間の到達で元に戻ります。次の発話を待つ予約機能ではありません。

## API / MCP

- 一覧: `GET /api/runtime/effects`（MCP操作 `output.effects`）
- 開始・停止: `POST /api/runtime/sessions/{sid}/effect`（`output.effect`）
- 結果: `GET /api/runtime/sessions/{sid}/effect/{request_id}`（`output.effect_result`）

MCPは `svg_describe` で引数を確認してから、`svg_write` に操作名・path・bodyを渡します。開始bodyの例:

```json
{
  "request_id": "happy-001",
  "preset": "happy",
  "strength": 0.7,
  "duration": 6,
  "until_speech_end": false
}
```

`preset` は `dissolve` / `appear` / `comms` / `happy` / `none`。停止は新しいrequest_idで `none` を送ります。

HTTP 202は受付です。出力画面が描画すると `running`、時間が来ると `completed` を返します。置き換え・発話終了などによる途中解除は `interrupted`、描画エラーは `failed`、切断や応答期限超過は `unknown` です。同じID・同じ内容は重複送信せず、異なる内容なら409になります。結果不明時は状態を確認し、無条件で再送しないでください。

## 描画と対応範囲

出力画面と配信表示は開始時刻と演出設定を共有します。途中で配信表示を開いても進行中の位置に合流します。接続が切れると演出を解除し、再接続時に勝手に再生しません。

今回の演出は、描画済みキャラクターの形・色を使うCanvas合成です。SVGの線や塗りを直接ばらしている実装ではありません。編集したSVGにも元画像を優先する表示にも対応し、素材自体は書き換えません。粒は最大1,400個、消滅マスクは長辺192ピクセルに制限しています。

OSの「動きを減らす」が有効なら、消滅はフェード、通信中の走査は静止、星は静止表示になります。字幕への効果、動画書き出しへの焼き込み、外部音声アプリとの専用連携、演出の同時重ね合わせは今回の対象外です。

追加: `preset: "ink"` は線から色への登場。暗い画素から線を近似抽出して4秒程度で色を広げます。常設の縁取り・ライティング・色変更・感情画像は[配信の見た目](broadcast-look.md)を使います。

# AI補正 P1–P3：実装と検証

2026-09-09。P0の補正候補に、外部AIの視覚レビュー、ImageGen差分の往復、登録素材からの開始を接続した。アプリ自身はクラウドAIを呼ばず、外部エージェントが判断と生成を担当する。

## 利用できる経路

| 入口 | 実装した処理 |
|---|---|
| 自分で作る | 従来の元画像＋PSD変換、編集、保存。AI接続不要。補正候補パネルも手動で使える |
| AIに仕上げを頼む | 現在の編集を固定 → 依頼文をコピー → 外部AIが受理 → 比較・数値補正・所見 → 適用または別保存 |
| 最初からAIに任せる | 元画像＋PSDを登録 → 空の編集画面で接続 → 外部AIが変換開始・監視・読込 → 同じ補正候補へ合流 |
| 画像生成を併用 | 利用を指定した依頼で参照PNGを出力 → 外部ImageGen → PNGの切り抜き・透過検証・SVG化 → 閉じ形だけ交換 → 再比較 |

実際の操作は [外部AIの操作ガイド](ai-assist-agent-guide.md) を参照。サーバーとブラウザーは更新後に再起動・再読み込みする。

## 保持と復旧

- セッションは `data/assist/sessions/<UUID>/000001.json.gz` のように追記保存。開始時のプロジェクトを1つ保持し、履歴には変更対象の状態を保存する。比較ZIP・生成参照・別保存プロジェクトは従来の `data/exports/<新規ID>/`。
- 保存時は期待する保存バージョンを照合。別の書き手との競合を409で返す。保存に失敗したコマンドはメモリ上の候補と回数を戻す。適用の保存失敗時も現行編集を復元する。
- 操作IDと結果も保存。再開後の同じ操作は再適用しない。通信断で保存結果が不明な場合は、セッションを再開して同じIDを照合する。
- 素材登録は `inputs/`、生成依頼は `requests/`、生成PNG・抽出PNG・SVGは `assets/` に保持。変換ジョブIDは実行開始前に入力へ保存し、同じ入力の二重変換を防ぐ。
- サーバー停止後、完成済み変換は保存済みプロジェクトから復旧。途中停止した変換は `interrupted` と表示して再登録へ戻す。
- 保存サイズ48MB、候補履歴60回、操作結果200件、チェックポイント250世代。生成PNG20MB・16MP以下、対象スロット各辺4096px以下。既存の空き容量ガードを通し、自動削除しない。

## 実物を通した検証

本検証は小さな合成顔＋対応PSDを使用した。ユーザーの原素材には変更を加えていない。

| 段階 | 結果と証拠 |
|---|---|
| P1 | 画面の「AIに仕上げを頼む」から依頼。画像を見て、画面左の閉じ目の下ずれ10px・幅1.4倍、閉じ口の下ずれ12px・幅1.5倍を補正。比較・所見・保存・適用・Undo・再読込まで確認。`qa/p1-review-9abf23b5/result.json` |
| P2 | 内蔵ImageGenを実際に1回使用。透過の閉じ口PNGを生成し、55×32pxのスロットへ明示配置してSVG化。候補へ差し込み、開閉・動きの画像を確認。`qa/p3-review-8511450a/result.json` |
| P3 | 開始画面で原画・PSD・希望・生成利用を登録。空の編集画面から外部クライアントが変換・読込・補正まで進行。同じ素材を通常変換でも処理し、部位の役割と配置が一致。`qa/p3-review-8511450a/recovery.json` |
| 復旧 | ブラウザー再読み込みで候補revisionと生成素材を復旧。サーバー再起動後も履歴の再開・保存済み操作の再送・変換状態の復旧を確認 |
| 出力 | P2候補を別保存後、通常のローダーで再読込。PNG・アニメーションSVG・プロジェクトを出力。SVGは1,770個のアニメーション要素を持ちXMLとして解析可能。`qa/p3-review-8511450a/exports.json` |
| 元素材保持 | 再出力プロジェクトと開始時を照合。SVG内IDの再付番を正規化し、閉じ口以外のSVG・開き形・部位配置・役割が一致 |

生成PNG：`qa/p3-review-8511450a/generated-mouth.png`。生成された線は、自動作成線より微笑みに寄り、縮小・SVG化後は少し柔らかい。完全閉眼、口開度0/25/50/100%、待機モーションのサンプルを確認した。絵柄の採否はユーザー確認が必要。

P1では位置と幅のずれは改善したが、80%閉眼付近には既存の開閉ブレンドの二重線が少し残る。所見へ未解決点として記録した。合成素材での成立確認を、多様な絵柄での品質保証とは扱わない。

自動検査：`npm test` **95件PASS**、`python -m unittest discover -s tests -p 'test_*.py'` **65件PASS**。追加検査は追記保存・保存競合・入力検証・PNG抽出・二重変換防止・履歴復元・再送・編集回数・生成利用拒否・終了後の素材拒否・保存失敗からの復元。

`web/verify-assist.html?session=<試験session_id>` は合成顔用のブラウザー検査。口の開度だけを変えたとき、目の画素が変わらないことを通常描画と比較PNGで検査する。固定の検査領域は320×360の試験素材用であり、任意の絵を評価する品質判定器ではない。

## 設計案から試作として絞った範囲

| 設計上の構想 | 現在の試作 |
|---|---|
| 全手動操作を共通revision管理 | 補正候補内は共通revision。通常編集との競合は開始時の内容との比較で拒否 |
| AI作業中の手動編集を自動で検知・一時停止 | 現行編集と候補は独立。採用時に競合を検出。自動一時停止は未実装 |
| 任意の生成画像を自動位置合わせ | AIが画像を確認し、cropと配置確認を明示。cropを対象寸法へ合わせ、必要なら共通の位置・拡縮・回転を追加 |
| マスク・周辺cropも揃えた生成パッケージ | 全体参照PNG、対象座標・寸法、元閉じ形のハッシュ。専用マスク自動生成は未実装 |
| PNG/SVG素材を直接取り込み | 生成PNGを検証・SVG化して閉じ形へ取り込み。任意SVGアップロードの専用UIは未実装 |
| 比較の短い動画 | 17ポーズのPNGとmanifest。通常のアニメーションSVG書き出しは利用可能 |
| あらゆる処理を即時中断 | 生成待ちなどコマンド間に候補を終了可能。比較画像の描画中は完了を待つ |
| AI利用量の自動測定 | アプリ内の数値編集回数と素材依頼数を制限。外部生成の消費量は収集しない |
| 実素材5条件での評価 | 今回は合成素材1種。実素材での採用率・作業時間の評価は未実施 |

OBS本体、実マイク、MP4/WebM、複雑な実イラストの再検証は今回のP1–P3検証に含めていない。

## 主要ファイル

- `web/assist-controller.js`：受理・候補編集・レビュー・生成依頼・採用・保存
- `web/edit-commands.js`：共有編集、履歴と競合検出
- `web/assist-entry.js` / `web/assist-panel.js`：2つのAI入口と結果確認
- `web/review-renderer.js`：固定条件の比較画像と生成参照
- `studio/assist.py`：永続化、登録入力、生成PNGの取り込み
- `studio/control.py`：型付き編集コマンド
- `tools/assist_agent.py`：外部エージェント用クライアント
- `tools/prepare_assist_test_inputs.py`：試験用原画・PSDを新規IDのフォルダに生成

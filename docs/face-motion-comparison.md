# Anime2.5DRigとの顔向き比較

参照：E:/other_repo/Anime2.5DRig/lib/app.js の deform（678行以降）、レイヤー設定（474行以降）。以下の「違い」は改訂前の調査。改訂内容は末尾を参照。

## 違い

Anime2.5DRigはレイヤーgroupに対し頭1、身体0.16、首は位置による連続した重みを使い、共通の首支点で回転する。layer.depthを左右・上下の移動量へ反映し、関連パーツが別々に動いても同じ頭部に見えるようにする。各レイヤーの奥行きも調整できる。

本アプリのface-rig.jsは同実装から移植した頭部追従をすでに持つ。ただし、前髪・後ろ髪・装飾品の奥行きは主に固定値で、Faceは胴体の巻き込みを防ぐ局所的な重みになっている。素材全体のまとまりと局所保護の差がある。単に振幅を大きくすると、首の隙間や髪とのずれが目立つ。

## 改訂方針・実装

パーツ別の調整UIを足す前案は撤回。標準の奥行きを参照実装の役割別設定へ合わせ、連動は自動にする。表の操作は左右・上下・傾きの3軸と待機切替。詳細は [顔の向きの実装・検証](head-coordination-verification.md)。

# SVGレイヤー補正と動かすレイヤーの選択

## 画面

- 01 の開閉スライダーをコンパクトにし、Undo/Redo をその下へ移動。
- 新しい自動閉じ口は、元の傾き・色を残す浅い笑顔。未調整の旧21点生成輪郭が逆向きの場合だけ読込時に補正する。PSD差分と数値編集済みの口は維持する。
- PSD／元絵切替とPSDブラシ切り出しの入口を非表示にし、「その他の調整」に「レイヤーの補正・結合」を配置。
- ブラシはベクターの描き足しとマスク消去。スポイトは選択中レイヤーから採色する。ホイールで拡大、移動ツールか中ボタンで移動。Undo/Redoは補正画面内30操作。「適用して戻る」で編集プロジェクトへ反映、「キャンセル」で破棄。
- 結合は隣接する通常レイヤー同士。元の重なりと各レイヤーの透明度をSVGに保持し、動きは補正中のレイヤーへまとめる。目・口の差分、顔下地は対象外。連動設定が不正になる結合は反映前に拒否する。
- 補正したレイヤーは元PNGへ戻さずSVG描画を使用する。配信、動画、プロジェクト保存も同じデータを使う。
- 02 の耳・尻尾・翼は自動推定を既定とし、任意レイヤー／なしへ変更可能。左右が別レイヤーの場合、支点を調整するレイヤーを選んでそれぞれ指定する。選択と支点はプロジェクトに保存。

## API / MCP

`editor.command` (`POST /api/control/commands`) の `action: "layer_edit"`。接続中の編集画面が必要。MCPも同じ操作を使用する。

```json
{"action":"layer_edit","layer_edit":{"operation":"inspect"}}
```

結果の `revision` を `expected_revision` に指定する。変更は全レイヤーのSHA-256で競合を検出し、古い値を拒否する。既存のコマンドIDと結果ポーリングによる再送・進捗・失敗確認を利用する。

- `stroke`: `part_id`, `mode: paint|erase`, `color: #rrggbb`, `size: 1..200`, `points: [[x,y],...]`（キャンバス座標、最大10,000点）
- `merge`: `part_id`（動きを残す側）, `other_id`（隣接レイヤー）, 任意 `name`
- `target`: `kind: ear|tail|wing`, `target: auto|none|pNNN`（耳のみ `both` で推定した左右を同時指定）
- `pivot`: `part_id`, `x`, `y`（キャンバス内）
- `secondary`: `part_id`, `secondary: {enabled, amount, cycles, range, region, direction}`。服・小物の追加／更新／解除。`direction` は `horizontal`（横、既定）・`vertical`（縦）・`diag-down`（左上から右下）・`diag-up`（左下から右上）。範囲は既存の正規化座標と4096画素マスクを使用する。UIと同じ `applyLayerEdit` から変更する。

UIとAPIは `applyLayerEdit` / `chooseAccessory` を共用する。ブラシ画面を開いている間は外部の `layer_edit` を拒否する。UIのズーム・ブラシカーソル・スポイト・ローカルUndoは画面専用。結果画像は既存の `export` のPNG、保存はproject形式から取得可能。

永続化：`parts[].earMotion / tailMotion / wingMotion` は省略時に自動、明示boolで対象指定。`pivotX/Y` と編集済み `svgText`、`rasterDisabled` を保持する。

## 調整メニューの更新

- レイヤー補正の「他のレイヤーの表示濃度」は初期70%、0〜100%で調整できる。補正画面だけの表示設定で、SVGと保存時の透明度は変えない。表示だけ変更した場合はプロジェクトに変更を記録しない。
- 耳は翼・尻尾と同じ小見出し。「両耳（左右をまとめて動かす）」で左右を同時に有効化し、支点はそれぞれ保持する。
- 翼も「両翼（左右をまとめて動かす）」に対応し、左右の支点を個別に選べる。
- 「待機中の動きの調整」を非表示。既存の左右・傾きの待機量は保持し、上下の繰り返し・うなずき・身体の追従と首支点を「顔の向き」に集約する。
- 話すときの眉は設定がない場合にON。明示的に保存されたOFFは維持する。
- 服・小物は「＋ 揺れを追加」で複数パーツを個別に登録する。1パーツにつき1つの範囲で、楕円／ブラシで補正可能。追加済みは追加候補から除外し、解除すると候補へ戻す。
- 服・小物の揺れ方向は、横・縦・斜め（左上→右下）・斜め（左下→右上）から選ぶ。未指定の既存プロジェクトは横として扱う。横以外は画像の横方向専用ワープを使わず、ベクターメッシュで指定方向へ動かす。
- `tests/motion-menu.browser.cjs` で表示濃度の非破壊性、両耳・個別支点、統合した設定、眉ON、2パーツの追加・設定維持・解除を実画面で検証する。

# 胸揺れの範囲補正（2026-09-16）

## 操作

「動きをつける → 身体 → 胸揺れ → 位置・範囲を補正」で、停止したキャラクターに楕円のガイドを表示する。
クリック／ドラッグで中心、右端／下端の丸で幅・高さを変更できる。スライダーと中心の矢印キー操作にも対応する。
適用して戻ると反映し、キャンセル／Escapeでは下書きを破棄する。自動推定への復帰、プロジェクト保存、既存プロジェクトへの適用に対応。

独立した胸パーツがある場合は、そのパーツ自体が揺れる既存動作を維持する。補正は胴体の局所変形が対象。
API引数は `agent-control.md` を参照。調整中は外部編集コマンドを拒否して下書きとの競合を避ける。

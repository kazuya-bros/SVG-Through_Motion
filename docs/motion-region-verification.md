# 範囲を指定する動きの調整（2026-09-19）

## UI

- 閉じ口の左右口角は非表示。既存値は保持。
- レイヤー表示は日本語名（取得できるSee-Through名）。PSD由来の接頭辞を省く。元のname/sourceLayerNameは判定・来歴用に保持。
- 「パーツの絵を確認」は「PSD／元絵の切り抜きを切り替え」に改名。
- 身体の弾み設定を非表示にし、準備画面で「一度弾む」を実行。表示先へposeを配信する。今回の手動トリガーは画面専用。APIで繰り返す弾みを設定する既存契約は維持。
- 胸：従来の楕円補正とブラシ補正を選択。服・小物：対象選択→楕円またはブラシ→確定で追加。既存の有効な揺れは一覧に残す。
- ブラシは塗る・消す・取り消す・クリア。編集は複製上で行い、プレビュー内の確定で適用。キャンセル・工程移動では破棄する。
- 眉の対象選択と補修後チェックは非表示。翼は未検出でも「対象レイヤーなし」を表示。

## 共通データと制限

settings.chestMotionRegion、parts[].secondaryMotion.region は正規化したcx/cy/rx/ry（0〜1、半径は0.005以上）、任意mask（64×64、4096要素、整数0〜255）。chestMotionRegion=nullは従来の自動／楕円推定。UIとプレビュー・配信・動画保存が同じ重みの処理を使う。ブラシはピクセル単位の切り抜きではなく、柔らかい動きの範囲指定。

胸はeditor.command settings / assist motionにchestMotionRegionを指定可能。服・小物のregionは補正プロジェクトの取得・適用でsecondaryMotionと一緒に保持。手描きストロークUIは画面専用、エージェントは結果の重みを渡す。形や値が不正な範囲は拒否する。細い塗りの境界でもメッシュが反転しないよう、重みの勾配から変位の上限を決める。

新しい範囲設定を選ぶと初めて任意の対象を局所変形する。連動元・先を増やす機能とは別。旧裾の行単位の最適化は維持し、範囲指定したパーツだけ分割数を増やす。

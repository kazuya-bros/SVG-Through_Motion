# 展示会モード

AI補正の導線は通常起動でも非表示です。`?exhibition=1` の指定は不要です。

このモードでは、次の表示だけが隠れます。

- 素材読み込み時の「AIに任せる」仕上げ方
- 目・口の編集画面にあるAI補正ボタン
- AI補正結果カードと、AIエージェント操作ガイド

通常の編集、AI演出、API / MCPからのAI補正はそのまま利用できます。開発中にAI補正の画面を確認するときだけ、URLに `?show-ai=1`（他のパラメータがある場合は `&show-ai=1`）を追加してください。

「01 形を整える」は「1 目 → 2 口 → 3 その他の調整」の順に進みます。
目・口は手動補正を開始した状態で開き、完了・キャンセルで確認状態へ戻せます。
レイヤー一覧、重なり順、透明度などの調整は「その他の調整」に表示します。
3つのタブは常に選び直せます。「その他の調整」が不要なら、そのまま「次へ：動きをつける」で進めます。

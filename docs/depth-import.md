# 通常素材のDepth PSD

開き目・開き口の通常PSDに対応するDepth PSDを、読み込みSTEP 2の「奥行きの補助（任意）」で追加できます。元絵と通常PSDは従来どおり必須です。Depthがなくても既存の機能は使えます。

## 入力条件

- 通常素材と一緒に出力したグレースケールのDepth PSD。差分素材のDepthではありません。
- 通常PSDと同じキャンバスサイズ。使用するFace・前髪・後ろ髪・頭飾りのレイヤー名と位置も対応している必要があります。
- 対応するFaceレイヤーが必須。髪・頭飾りの深度は、対応するレイヤーがある部分だけ使います。
- 各PSDは100MB以下、100レイヤー以下。自動で拡縮・位置合わせはしません。条件が合わない場合は変換エラーで理由を表示します。

## 反映と保存

読み込み後の「動きをつける → 顔・瞳」に「Depthで奥行きを補助」が表示されます。オン・オフと補助の強さ（0〜100%）を変更すると、プレビューへ即時反映します。0%とオフは既存の動きと同じです。顔向きX/Yに応じて顔内の移動量と、前後の髪・頭飾りの視差を補助します。

閉じ目・閉じ口・母音の絵は通常素材のFace深度を共用します。差分切替時に別のDepthへ切り替わることはありません。Depthは支点や物理的な柔らかさを決めるものではなく、腕・尻尾・服に新しい変形を追加する機能でもありません。

描画には既存の共有変形処理を使い、プレビュー・アバター・Canvasによる動く素材出力へ反映します。リグを止めて静止素材を作る出力ではDepth補助も止まります。旧来の軽量SVGフィルター出力へDepth機能を追加したものではありません。

深度はプロジェクトの `rig.depth` に、65×65の平滑化した格子、基準値、対象パーツの代表値として保存します。プロジェクト保存・再開・持ち運び時に元のDepth PSDを参照する必要はありません。表示制御は `settings.depthEnabled` と `settings.depthStrength`（0〜1）。非対応・破損した深度格子は読み込み時に除外します。Depthのない既存プロジェクトの絵と動きは変えません。

## API

`POST /api/import/hybrid` の任意ファイルフィールド `depth_psd` に通常素材のDepth PSDを指定します。`eyes_closed` / `mouth_closed` などの差分フィールドとは独立しています。`defer=true` のAI依頼用取り込みもDepthを保持して変換します。`GET /api/health` の `depthImport: true` で対応を確認できます。

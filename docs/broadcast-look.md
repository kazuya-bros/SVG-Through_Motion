# 配信の見た目

「キャラクターを使う」から開く配信準備の上部で設定します。同じセッションのOBSブラウザソースにも反映します。瞬き・口パク・視線・顔の動きは従来の描画処理を使い続けます。

## 操作

- 白→色→白の縁取り：キャラクター全体の合成後の輪郭に付けます。色・幅を変更できます。画像の端に接した部分は出力領域で切れます。
- ライティング：昼／夕方／夜／ネオン／背景画像の平均色。画像は光の参考専用で、背景自体は配信しません。クロマキーの緑・青を光として拾いません。OBS内の背景を自動取得する機能ではありません。
- パーツの色：パーツ、元の色、変更後の色を選びます。近い色の範囲を調整可能。暗い線と白いハイライトを保護し、SVGの塗りを元色から更新します。マスク・クリップの図形は変更しません。生成済みの目・口の差分は対象外です。色変更中は前の描画を続け、準備完了後に差し替えます。
- 感情：照れ／どんより／登録画像。照れ・どんよりは顔の下地に重ね、その後で目や髪を描くので髪を染めません。顔の下地が識別できないキャラクターではこの2種類は表示されません。画像は頭の位置を基準に追従し、大きさ・左右・上下・濃さを調整できます。PNG・JPEG・WebP、8MB・16MP以下。登録時に長辺2048px以内のPNGへ正規化します。
- 登場：暗い部分を抽出した線が現れた後、左から色が広がります。4秒。線画レイヤーや筆順を推定する処理ではないため、暗い塗りも含まれます。「動きを減らす」設定時はフェードです。
- 見た目のプリセット：名前を付けて保存し、次回も呼び出せます。画像はアプリの保存先に登録されるので元ファイルの移動には影響されません。プリセットのパーツ色指定は元キャラのパーツIDを使います。他のキャラで同じ設定を使う場合は対象を確認してください。

吹き出し、怒り・潤みなど試作時の図形エフェクトは追加していません。任意画像で置き換えられます。動画の「03 保存」への焼き込みと、プロジェクトファイルへのこの見た目の埋め込みは対象外です。配信設定と画像は「見た目のプリセット」とアプリ内画像ライブラリで保存します。

## 配信中

準備に戻って調整するほか、このウィンドウにフォーカスがある時は以下のキーで操作できます。画面上の操作パネルを配信モードに重ねる変更はありません。

| キー | 動作 |
| --- | --- |
| Alt+1 | 縁取りの切り替え |
| Alt+2 | 光の種類を切り替え |
| Alt+3 / Alt+4 | 照れ／どんよりの切り替え |
| Alt+5 | 登録した感情画像の切り替え |
| Alt+6 | 線から色への登場 |
| Alt+0 | 感情を解除 |

入力欄の操作中は反応しません。OSのグローバルホットキーではありません。AI/APIからの変更も同じ設定・レンダラーを使用します。

## API / MCP

既存の `stage.state`、`stage.configure`、`stage.perform`、`stage.upload`、`stage.save_preset` 相当の操作を利用します。正確な操作名とURLは `svg_operations` / `svg_describe` または `/api/agent/operations` で確認してください。

`GET /api/stage/sessions/{sid}` の `baseline.appearance` を更新します。`PUT`では取得した最新 `revision` と現在の `mode` を指定し、他のbaselineフィールドを維持してください。競合は409、不正値は422、未登録画像は404。古いrevisionの再送は再適用されません。状態を読み直して結果を確認します。

```json
{
  "outline": true,
  "outline_color": "#8c91db",
  "outline_width": 6,
  "light": "sunset",
  "light_strength": 0.5,
  "light_color": "#e3be97",
  "light_asset_id": null,
  "emotion": "blush",
  "emotion_strength": 0.6,
  "emotion_asset_id": null,
  "image_scale": 0.22,
  "image_x": 0,
  "image_y": -0.15,
  "colors": []
}
```

色は `colors: [{"part_id":"p006","from_color":"#ec8c51","to_color":"#668bc6","tolerance":0.08}]`。1パーツ1設定、最大24件。パーツIDは実際の出力プロジェクトから取得します。

画像は `/api/stage/assets` へ登録し、返されたIDを `light_asset_id` または `emotion_asset_id` に設定。感情画像は `emotion: "image"` を同時指定します。AIによる一時演出ではレシピの各 `steps[].scene.appearance` に同じ構造を指定します。画像のロードと色変更後の描画を待ってrunningを報告し、終了後はbaselineに戻ります。画像の準備・色変更失敗は既存の演技結果のfailedで確認します。

登場は `POST /api/runtime/sessions/{sid}/effect` に `preset: "ink"`。既存のrequest_id、再送検出、結果照会、OBS同期が利用できます。`stage`の一時効果が優先する場合は、その演技を解除してから登場を実行してください。

APIでbaselineの設定を受け付けた時点では、色変更の描画準備が続いている場合があります。画面には進捗・失敗を表示します。`GET /api/stage/sessions/{sid}/preview`で実際の合成結果をPNGとして確認できます。見た目プリセットは8秒のレシピとして既存の永続ライブラリへ保存し、画面の呼び出しではappearanceを通常設定として適用します。

## 技術上の範囲

SVGの色変更は指定パーツのfill/stroke/stop-colorを変更し、描画キャッシュを再生成します。毎フレームのSVG解析はしません。ライト、輪郭、登場、画像はCanvas合成です。これらの合成自体はPNGでも可能です。ライティングは色調の近似で、立体形状や光源から影を再計算するものではありません。

顔の色の重ね合わせはパーツの変形前、輪郭・光・登場はキャラクター描画後、任意の感情画像は最後に合成します。配信とOBSは共通の状態・描画コードを使用します。

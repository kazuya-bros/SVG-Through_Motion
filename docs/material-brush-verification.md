# ブラシによる素材切り出し — 2026-09-16

PachiPakuGenのローカル実装（`src/App.tsx` の切り出し作成・ブラシ・消し・ぼかし）を確認し、矩形選択しかなかった素材補正へブラシ選択を追加。

## 操作と保存

- SVG編集の左側に「PSDのブラシ切り出し ↗」。別画面なので編集中のプロジェクトを維持する。素材補正由来のプロジェクトは元素材へ、それ以外はPSD選択へ進む。
- 素材補正では各レイヤーに「ブラシで切り出す」。対象だけを表示し、赤い選択範囲と結果プレビューを並べる。
- ブラシ、消し、サイズ、境界のぼかし、一筆戻す、全消去、名前、元から分離／複製、キャンセル。
- 確定時は既存の `materials.extract` APIへPNGマスクを渡す。元ファイル・旧assetを保持し、切り出したレイヤーを選択。移動・倍率・不透明度・元への追従を保持。
- 切り出し後の「元に戻す」で元のassetに戻せる。補正後はPSD保存またはSVG変換へ進む。既存SVGへの自動反映は対象外。

## 検証

- Python素材テスト9件、agent controlテスト5件、JavaScriptブラシ／素材テスト7件成功。
- 非矩形PNG、半透明マスク、移動・倍率、元画像保持、既存crop、複製、空／不正／異寸法マスク、revision競合を確認。
- 実PSDのQAコピーでブラシ・ぼかし・消し・一筆戻し・確定をUIから実行。手先を179×183px、選択画素19,120pxの別レイヤーへ分離し、元腕へのparentと位置を確認。
- 切り出し後の元画像と新レイヤーのアルファ合計が、元のアルファと画素単位で一致することを確認。
- 確定後の取り消しと保存で元の26レイヤーへ復帰。別の下書きをキャンセルしてrevisionが変わらないことも実画面で確認。
- スクリーンショット: `qa/material-brush-cutout.png`、`qa/material-brush-entry.png`。

柔らかい境界は部分透明になるため、分離後の重ね方や背景によって境界の見え方が変わる。実素材に合わせてプレビューで調整する。

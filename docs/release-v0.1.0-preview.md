# SVG-Through Motion v0.1.0-preview

展示会と動作確認向けのWindows用テスト公開版です。

## 配布

GitHub Releaseの添付ファイル `SVG-Through-Motion-0.2.0-windows-x64-20260920-132736.zip` を展開して起動してください。

## 主な確認対象

- 元絵＋See-Through PSDの読み込みとSVG化
- 瞬き・口パク・顔向き・髪・耳・翼・服・小物の揺れ
- 服・小物の横／縦／斜め方向指定
- 両耳・両翼のまとめ操作と左右別支点
- 演出、配信表示、透過WebM／MP4保存

## 既知の制限

- パス数の多い素材や複数の揺れを同時に使うとプレビューやWebMが重くなることがあります。
- PSDの調整レイヤー、複雑なマスク、ブレンドモードは完全には再現しません。
- 素材によって線の残り、境界、補正品質に差が出ます。
- 音声に合わせた正確な音素口パクやTTSはこのプレビューの中心機能ではありません。

問題報告時は、OS、入力画像のサイズ、PSDのレイヤー構成、再現手順を添えてください。元画像やPSDを公開したくない場合は、個人情報や素材そのものを含めず症状だけ報告してください。

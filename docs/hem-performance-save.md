# 裾の描画負荷と名前・保存先の選択（2026-09-20）

## 裾の描画

ブラシ／楕円で指定した服の横揺れは、細かい三角形ごとの画像再描画から、横方向の画素対応を走査する処理へ変更。既存の揺れ範囲・振幅制限を使い、元の透明度を保って補間します。通常の体の傾きなどは、その後に既存の変形で適用します。頭・耳・連動パーツは従来の処理を使います。

`tests/cloth-warp.browser.cjs` の実素材比較：

- 1フレームのdrawImage呼び出し：平均1,230回 → 206回。
- 同一試行の描画処理：平均110.8ms → 85.9ms。ヘッドレスChromiumでの値で、端末のfpsを保証するものではありません。
- 5姿勢の画素比較：0〜255値の平均差は最大0.030未満。元の不透明画素が消失する欠けは0。
- 別の連続測定でも、範囲付きの裾の追加負荷は、揺れのない状態とほぼ同じまで減少。

停止中・保存ダイアログ表示中は、同じプレビューを毎フレーム再描画しません。パラメーターや表示姿勢が変われば更新します。

## 保存

「プロジェクトを保存して完了」と、ロゴからの「保存して戻る」で、名前を入力しWindowsのファイルダイアログから保存先を選べます。保存先ファイル名とプロジェクト内の表示名は別々に指定できます。キャンセル時は編集画面に残ります。従来のメインメニューの履歴用コピーもアプリ内に保持します。

### API / MCP

- `POST /api/project-saves/choose`：`request_id` と `name`。Windowsの保存先ダイアログを開き、`ticket`・`path`を返します。ダイアログ内の選択はユーザー操作です。キャンセルはticket=null。
- `POST /api/project-saves/{ticket}`：プロジェクトJSON本体（最大100MB）を選択済み保存先へ保存します。MCPの操作名は `project_save.write`。
- `GET /api/project-saves/{ticket}`：busy / selected / saved / cancelled と保存結果。

書き込み先の生パスはクライアント引数で受け付けません。選択は30分有効。同じ選択IDと内容の再送は同じ結果を返し、異なる内容は409。別アプリが選択後にファイルを変えた場合も409。保存は一時ファイルから置換し、保存失敗時に既存ファイルを途中まで上書きしません。Windows以外の保存先ダイアログは501。

## 検証

- ブラウザ：実際のWindows保存ダイアログで検証フォルダを選択、名前変更、保存、メインメニューへ戻る、外部保存したJSONを再読み込みして裾の設定維持を確認。

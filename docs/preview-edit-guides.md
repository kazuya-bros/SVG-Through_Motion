# ブラシ・パーツ選択・感情の位置調整

## 操作

- 02「服・小物」の動かすパーツを開くと、サムネイルと名前の一覧から選べます。追加済みの揺れにもサムネイルを表示します。
- ブラシの円をホバー中・塗っている間に表示します。消すモードは赤い破線です。大きさは元絵上の直径で、拡大表示にも追従します。
- プレビュー枠の余白を除き、元絵と同じ縦横比・座標で塗った範囲を表示します。楕円からブラシへの切替では既存の範囲を引き継ぎ、クリアすると空から塗れます。
- 照れ／冷や汗の「プレビューで位置を調整」で中心の十字と範囲を表示します。十字のドラッグ、画面クリック、矢印ボタン／キーで位置を変更できます。矢印は元絵の1px、Shift併用で10pxです。
- 大きさ・間隔・角度のスライダーもガイドに反映します。位置合わせ中はキャラクターの動きと登場演出を止めます。「確定」で採用、「キャンセル」またはEscで調整開始時の位置・大きさ・間隔・角度に戻します。

## 共通処理と検証

サムネイル選択・カーソル・十字ガイドは画面専用の操作補助です。保存する領域マスク、secondaryMotion、appearanceのフィールドやAPI契約は変更していません。感情の変更は既存の演出プレビューAPI、保存は既存の演出保存APIを利用します。ガイドは出力用canvasに描かず、配信画像には含めません。

`tests/preview-edit-guides.browser.cjs` で実素材を読み込み、サムネイル選択、ブラシの縦横比、ホバー／ストローク／消去カーソル、拡大・画面リサイズ、照れ・冷や汗のドラッグ／微調整／角度追従／確定／キャンセルを確認。画面例外なし。既存Nodeテスト284件成功。

実画面は `output/verification/motion-part-thumbnails.png`、`motion-brush-cursor.png`、`emotion-placement-guide.png`。

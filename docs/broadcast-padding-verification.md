# 配信中の頭頂・縁取りの欠け（2026-09-20）

原因は元画像サイズに固定した描画用Canvas。今回の素材では耳の上余白が2px、後ろ髪が7pxで、待機モーションや縁取りが上端を越えて切れていた。

配信用に元画像長辺の15%ずつ透明な描画余白を追加。パーツ合成、変形メッシュ、縁取り、演出、最終合成に引き継ぐ。元の座標と画像は変更しない。既存メッシュを保ち、外周にだけ同じ向きの三角形を足してクリップ境界の隙間を防止する。表示倍率は元画像サイズ基準のまま。スポイト、照れ・冷や汗の位置調整も余白を考慮する。

確認：

- 実際の24パーツ素材で修正前後を同じ姿勢・640px基準で描画。修正前は上端223pxが不透明、修正後の外周上端は0px。以前の描画範囲より上に4,115pxの絵・縁取りが復元された。
- `tests/broadcast-padding.browser.cjs`でスポイト、拡大画面の顔エフェクト位置、OBS表示、JavaScriptエラー0件を確認。
- 関連JavaScript49テスト、および方向別演出と冷や汗のピクセル検証が成功。
- 実画面：`output/verification/broadcast-padding-ui.png`。
- 配布版：`output/desktop/SVG-Through-Motion-0.2.0-windows-x64-20260920-022353`。ネイティブ・Pythonバイナリは前版のまま、変更した外部Web資産8ファイルを更新。配布ファイルと検証したソースの一致を確認。

画面自体の外へ拡大・移動した場合の見切れは通常の表示範囲によるもの。今回の修正は画面内に見えている頭が、元画像の描画境界で水平に切れる現象を対象とする。

保存先と接続

保存済みの素材の場所を変更したり、See-Throughの環境を指定したりする画面です。通常は変更せず、そのまま使えます。

初回はアプリと同じ場所の data フォルダを自動で用意します。以前の素材を使う場合は、その data フォルダを選んでください。保存済みキャラクターを1つ開く操作は、メインメニューの「キャラクターを使う」から行えます。

詳細：See-Throughの場所・接続ポート

変更したら保存し、この画面下部の「アプリを終了」から終了して起動し直してください。

EXPRESSION SHORTCUTS

どの画面からでも、表情・演出を切り替える

ゲームやOBSを操作している間も使えます。この設定を開いた表示ウィンドウが操作対象に選ばれます。

「設定を保存・適用」で操作対象とキーを確定します。キーの割り当ては次回も引き継がれます。

キャラクター表情・演出グローバルキー切り替え方操作

CtrlまたはAltを含むキーを指定します。入力欄でキーを押すと組み合わせを入力できます。入力中は、その組み合わせが別アプリにも作用する場合があります。

ホットキーは停止中です。

    ホットキーはキャラクターの表示ウィンドウの操作パネルの「ホットキー設定」から設定できます。

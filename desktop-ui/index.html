制作をはじめる

素材とプロジェクトの保存先を選んで起動します。

以前の制作を続ける場合は、既存の data フォルダを選んでください。

See-Through・接続の設定

起動後の変更は、アプリを終了して再度起動すると行えます。

EXPRESSION SHORTCUTS

どの画面からでも、表情を切り替える

ゲームやOBSを操作している間も使えます。制作画面でキャラクターの出力を開いてから設定してください。

誤操作を防ぐため、アプリ起動後は操作対象を選び直します。キーの割り当ては保存されます。

表情グローバルキー切り替え方操作

CtrlまたはAltを含むキーを指定します。入力欄でキーを押すと組み合わせを入力できます。入力中は、その組み合わせが別アプリにも作用する場合があります。

ホットキーは停止中です。

    制作・出力画面の「アプリ」メニューから、この設定を開けます。
